# Идеи на потом

Не делать без отдельной просьбы — только список мыслей.

- **Виджет корпоративной почты** (27.10.2026). В шапке: число непрочитанных и последние письма
  (от кого, тема); клик — открывает почту. Как вариант — через тот же Apps Script, что и календарь
  (GmailApp: непрочитанные во «Входящих» → JSON по ссылке `…/exec`), без Google Cloud.
- **Голосовая активация** по фразе («запиши задачу» … «всё»), офлайн (например, Vosk).
- **Доски в стиле Excalidraw** — рисование схем рядом с задачами.
- **Дедлайны в Google Календарь** через Apps Script (обратная запись).
- **Свой сервер** для синхронизации вместо GitHub.
