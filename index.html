    Автоматически отправлять дедлайны в календарь
    Задачи с дедлайном становятся событиями на весь день; при выполнении или удалении задачи событие удаляется. Без настройки тоже можно: в открытой задаче есть кнопка «В Google», а в разделе «Данные» — экспорт .ics.
    Как подключить Google (один раз, ~5 минут)
    1. Откройте console.cloud.google.com под своим Google-аккаунтом → вверху «Select project» → New project (любое название, например «Задачи»).
    2. Меню ☰ → «APIs & Services» → Library → найдите Google Calendar API → Enable.
    3. «APIs & Services» → OAuth consent screen (или «Google Auth Platform») → тип External → название приложения и ваша почта → сохранить. В разделе Audience / Test users добавьте свою почту.
    4. «Credentials» (или «Clients») → Create credentials → OAuth client ID → тип Desktop app (Приложение для ПК) → Create.
    5. Скопируйте Client ID и Client secret в поля выше → нажмите «Подключить».
    6. Откроется ваш браузер → выберите аккаунт → «Продолжить» (Google предупредит, что приложение не проверено — это нормально, оно ваше) → разрешите доступ к календарю → вкладку можно закрыть.

    Вход нужен один раз: программа хранит ключ доступа в зашифрованном виде и сама продлевает его. Отключить — кнопка «Отключить».

    В браузерной версии (без программы) тип клиента — Web application, а в «Authorized JavaScript origins» нужно добавить адрес сайта; со страницы, открытой как файл, Google вход не разрешает.

    Календарь корпоративной почты Google: подключение через скрипт

    Если администратор запретил публичный и секретный адрес календаря (встречи приходят как «Busy»), календарь отдаёт ваш собственный скрипт Google Apps Script — со всеми названиями, временем, местом и описанием.

    Если скрипт уже создан (ссылка просто потерялась): script.google.com → ваш проект → «Начать развёртывание» → «Управление развёртываниями» → скопируйте URL веб-приложения (заканчивается на /exec) → вставьте его в «Добавить календарь» выше.

    Создать с нуля (≈5 минут):

    1. Откройте script.google.com под рабочей почтой → «Новый проект».
    2. Сотрите всё в редакторе, нажмите кнопку ниже и вставьте код (Ctrl+V) → Ctrl+S.
    3. Слева ⚙ «Настройки проекта» → часовой пояс (GMT+03:00) Москва.
    4. «Начать развёртывание» → «Новое развёртывание» → ⚙ рядом с «Выберите тип» → «Веб-приложение»; «Запуск от имени»: Я; «У кого есть доступ»: Все → «Начать развёртывание».
    5. Google попросит доступ к календарю → выберите аккаунт → «Дополнительно» → «Перейти к проекту» → «Разрешить».
    6. Скопируйте URL веб-приложения (…/exec) → здесь: название, например «Рабочий календарь», ссылка — этот URL → «Добавить по ссылке».

    Важно: после любого изменения кода скрипта — «Управление развёртываниями» → ✏ → «Версия: Новая версия» → «Развернуть», иначе работает старая версия (программа покажет «forbidden»). Ссылка при этом не меняется.

    Встречи загружает программа на ПК; телефон получает их через синхронизацию. Ссылку никому не публикуйте — по ней видны названия ваших встреч.

    Кнопка микрофона в редакторе
    Кнопка открывает диктовку Windows. Скажите «следующая строка», «новая строка» или «новый абзац» — текст перейдёт на новую строку. Сохранить — Ctrl+Enter или клик мимо. Для точек и запятых включите в окне диктовки (⚙) «Автоматическая расстановка знаков препинания».
    Кнопка включает распознавание речи браузера (Chrome, Edge, Safari). Скажите «новая строка» или «новый абзац» — текст перейдёт на новую строку. На iPhone можно также пользоваться микрофоном на клавиатуре.

    …или вставьте ссылку подключения
    Наведите камеру iPhone на код → откроется приложение уже подключённым. Затем «Поделиться» → «На экран Домой». В коде ваш токен — не показывайте его другим.
    Как настроить (один раз, ~5 минут)
    1. github.com → New repository → название task-data → Private → поставьте галочку Add a README file → Create.
    2. github.com → ваш аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    3. Repository access: Only select repositories → task-data. Permissions → Repository permissions → Contents: Read and write. Срок — до года (потом создать новый).
    4. Скопируйте токен (github_pat_…), вставьте выше вместе с Tekhnator/task-data → «Подключить». Все задачи с этого ПК уйдут в репозиторий.
    5. «Подключить телефон (QR-код)» → отсканируйте камерой iPhone.

    Синхронизация — каждые 30 секунд, через 3 секунды после правки и при возврате в программу. Каждая синхронизация — версия в истории репозитория: это и есть автоматический бэкап, любую прошлую версию можно достать. Настройки внешнего вида у каждого устройства свои; задачи, списки, папки и мои календари — общие.

    Данные
    JSON — резервная копия и перенос между компьютером и iPhone. «Импорт» открывает и автоматические бэкапы. Файл .ics можно импортировать в Google Календарь (calendar.google.com → Настройки → Импорт).
    Копии на этом устройстве
    Папки, списки, задачи и мои календари сохраняются сами: снимок на начало каждого дня (30 последних дней), «последняя» — через полминуты после правки, и копия перед импортом, восстановлением или очисткой.
    На ПК те же копии ещё и файлами в Документы\Задачи\Бэкапы — их можно вернуть через «Импорт (JSON)», даже если программа переустановлена.
    Версии на GitHub
    Каждая синхронизация — сохранённая версия. Можно вернуть данные на любой момент — на всех устройствах.
    Справка
    Инструкция
    1. Список — «+ Новый список» внизу левой панели; папка — кнопка с папкой рядом. Двойной клик — переименовать.
    2. Задача — «Новая заявка». Первая строка — заголовок, дальше обычный текст. Всё сохраняется само: можно нажать Enter или просто кликнуть в любое другое место.
    3. Голосовой ввод — кнопка микрофона в панели форматирования.
    4. Дедлайн — «Установить дедлайн» под задачей. Цвет полосы слева показывает срочность.
    5. Выполнение — кружок слева. Через 10 секунд задача уйдёт в «Выполненные» (повторный клик — отмена).
    6. Перенос в другой список — кнопка со стрелками у задачи или Alt+X, затем клик по списку.
    7. Порядок — перетаскивайте задачи за ⋮⋮, списки — мышью (в том числе в папку).
    Установка на iPhone
    1. Разместите этот файл на любом https-адресе (например GitHub Pages) и откройте его в Safari на iPhone.
    2. Нажмите «Поделиться» → «На экран Домой». Появится иконка, приложение откроется на весь экран, без адресной строки.
    3. Перенос задач с ПК: здесь «Экспорт (JSON)» → отправьте файл на телефон → на iPhone «Импорт (JSON)».
