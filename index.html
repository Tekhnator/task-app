    Google Календарь
    Встречи из Google добавляются в разделе «Календарь» ниже — по ссылке iCal (например, через Apps Script). Блок ниже — двусторонняя синхронизация (дедлайны задач уходят в Google как события); для неё нужен проект в Google Cloud, который сейчас недоступен для России.

    Автоматически отправлять дедлайны в календарь
    Задачи с дедлайном становятся событиями на весь день; при выполнении или удалении задачи событие удаляется. Без настройки тоже можно: в открытой задаче есть кнопка «В Google», а в разделе «Данные» — экспорт .ics.
    Как подключить Google (один раз, ~5 минут)
    1. Откройте console.cloud.google.com под своим Google-аккаунтом → вверху «Select project» → New project (любое название, например «Задачи»).
    2. Меню ☰ → «APIs & Services» → Library → найдите Google Calendar API → Enable.
    3. «APIs & Services» → OAuth consent screen (или «Google Auth Platform») → тип External → название приложения и ваша почта → сохранить. В разделе Audience / Test users добавьте свою почту.
    4. «Credentials» (или «Clients») → Create credentials → OAuth client ID → тип Desktop app (Приложение для ПК) → Create.
    5. Скопируйте Client ID и Client secret в поля выше → нажмите «Подключить».
    6. Откроется ваш браузер → выберите аккаунт → «Продолжить» (Google предупредит, что приложение не проверено — это нормально, оно ваше) → разрешите доступ к календарю → вкладку можно закрыть.

    Вход нужен один раз: программа хранит ключ доступа в зашифрованном виде и сама продлевает его. Отключить — кнопка «Отключить».

    В браузерной версии (без программы) тип клиента — Web application, а в «Authorized JavaScript origins» нужно добавить адрес сайта; со страницы, открытой как файл, Google вход не разрешает.

    Где взять ссылку на календарь
    • Google Календарь: calendar.google.com → ⚙ Настройки → слева выберите календарь → «Интеграция календаря» → «Секретный адрес в формате iCal».
    • Яндекс Календарь: наведите на календарь → ⚙ → «Экспорт» → скопируйте ссылку iCal.
    • Outlook: Параметры → Календарь → Общие календари → «Опубликовать календарь» → ссылка ICS.
    • Праздники других стран: в Google Календаре добавьте «Праздники» нужной страны и возьмите его ссылку iCal.

    Ссылочные календари обновляются сами (раз в 30 минут при открытии календаря) и кнопкой ⟳. В программе они работают всегда; в браузере некоторые сервисы ссылку не отдадут.

    Голосовой ввод
    Кнопка микрофона в редакторе
    Кнопка открывает диктовку Windows. Скажите «следующая строка», «новая строка» или «новый абзац» — текст перейдёт на новую строку. Сохранить — Ctrl+Enter или клик мимо. Для точек и запятых включите в окне диктовки (⚙) «Автоматическая расстановка знаков препинания».
    Кнопка включает распознавание речи браузера (Chrome, Edge, Safari). Скажите «новая строка» или «новый абзац» — текст перейдёт на новую строку. На iPhone можно также пользоваться микрофоном на клавиатуре.

    Справка
    Инструкция
    1. Список — «+ Новый список» внизу левой панели; папка — кнопка с папкой рядом. Двойной клик — переименовать.
    2. Задача — «Новая заявка». Первая строка — заголовок, дальше обычный текст. Всё сохраняется само: можно нажать Enter или просто кликнуть в любое другое место.
    3. Голосовой ввод — кнопка микрофона в панели форматирования.
    4. Дедлайн — «Установить дедлайн» под задачей. Цвет полосы слева показывает срочность.
    5. Выполнение — кружок слева. Через 10 секунд задача уйдёт в «Выполненные» (повторный клик — отмена).
    6. Перенос в другой список — кнопка со стрелками у задачи или Alt+X, затем клик по списку.
    7. Порядок — перетаскивайте задачи за ⋮⋮, списки — мышью (в том числе в папку).
    Установка на iPhone
    1. Разместите этот файл на любом https-адресе (например GitHub Pages) и откройте его в Safari на iPhone.
    2. Нажмите «Поделиться» → «На экран Домой». Появится иконка, приложение откроется на весь экран, без адресной строки.
    3. Перенос задач с ПК: здесь «Экспорт (JSON)» → отправьте файл на телефон → на iPhone «Импорт (JSON)».
