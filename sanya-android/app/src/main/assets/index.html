Настройки для взрослых

Изменения сохраняются сразу. Закрыть — крестик ✕ справа вверху.

Ключ Claude API

QR-код делается на компьютере на странице tekhnator.github.io/task-app/sanya-qr.html — в него можно положить и ключ, и текст «О Сане». Или просто вставьте ключ в поле, переслав его себе на планшет.
Ключ хранится только на этом планшете. Получить: console.anthropic.com → API Keys. Пополните баланс и поставьте лимит расходов.

Голос

Если голоса не слышно: установите бесплатный RHVoice (f-droid.org → RHVoice), в нём скачайте русский голос — приложение само его найдёт. В списке «Голос озвучки» потом можно выбрать другой голос.

Разговор без кнопки

Пока Клод говорит, микрофон на паузе, чтобы он не слышал сам себя. Перебить можно касанием лица. Ночью и после лимита времени микрофон выключается полностью. Если рядом работает телевизор, лучше выбрать «только на слова».

Музыка и звуки

Во время разговора музыка сама стихает, чтобы не мешать Сане и распознаванию речи.
Музыка (CC0, OpenGameArt): ночью — «Outer Space Loop» (wipics), «Baby Song» (Alex McCulloch); днём — «Birds, Wind and Synth» (Spring Spring), «Lost in the Meadows» (Augmentality).

Нужен русский голос

В планшете нет русского синтезатора речи, поэтому Клод не может говорить. Это делается один раз, бесплатно:

  1. Нажмите кнопку ниже — откроется загрузка бесплатного синтезатора RHVoice. Установите скачанный файл.
  2. Откройте приложение RHVoice → Русский → выберите женский голос (например, Анна или Ирина) и нажмите «Установить». Нужен интернет, голос весит несколько мегабайт.
  3. Вернитесь сюда — приложение само найдёт голос. Менять что-то в настройках планшета не нужно.
