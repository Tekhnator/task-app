# Задачи

Настольная программа-планировщик для Windows (Electron): папки и списки, задачи с
форматированием и картинками, дедлайны, календарь с праздниками, встречами и своими
календарями (iCal), виджеты в шапке (часы с календарём, калькулятор, секундомер,
погода с прогнозом на 7 дней, поиск), голосовой ввод через диктовку Windows,
темы оформления TRON, iPhone и Unibody (светлые и тёмные).

## Запуск

1. Установите [Node.js](https://nodejs.org) (LTS).
2. В папке программы один раз выполните `npm install`.
3. Запуск — `Запуск.bat` (или `npm start`).
4. Установщик для Windows — `npm run build`, результат в папке `dist`.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение: интерфейс и логика. Можно открыть и просто в браузере. |
| `main.js` | Окно программы; сетевые запросы (погода, праздники, календари), вход в Google, вызов диктовки Windows. |
| `preload.js` | Мост между страницей и программой (`nativeNet`, `nativeGoogle`, `nativeVoice`). |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | Версия для телефона: работа без интернета и иконка «на экран Домой». |
| `google-apps-script/calendar-feed.gs` | Скрипт, отдающий корпоративный Google Календарь ссылкой iCal (инструкция внутри файла). |

## Телефон (iPhone)

То же приложение открывается в Safari по адресу **https://tekhnator.github.io/task-app/**
(GitHub Pages из этого репозитория). «Поделиться» → «На экран Домой» — и оно запускается
на весь экран, как обычное, и работает без интернета (`sw.js`).

## Синхронизация ПК ↔ телефон

Данные лежат **не здесь**, а в отдельном приватном репозитории (например `Tekhnator/task-data`):

| Файл | Что внутри |
|---|---|
| `meta.json` | папки, списки и их порядок |
| `tasks/00.json … tasks/0f.json` | задачи, разложенные по 16 файлам |
| `calendars.json` | «Мои календари» и их встречи (телефон сам не может скачать ссылки iCal) |

- Каждая запись хранит время изменения; при слиянии побеждает более свежая.
  Удаление помечается, чтобы удалённое не «воскресало» с другого устройства.
- Синхронизация: через 3 с после правки, раз в 30 с и при возврате в окно.
  Если другое устройство успело сохранить раньше — сначала принимаются его изменения.
- **Каждая синхронизация — коммит**, поэтому история репозитория с данными — это и есть
  автоматический бэкап: любую прошлую версию можно достать.
- Доступ — токен GitHub (fine-grained, только репозиторий с данными, Contents: Read and write).
  На телефон он переносится QR-кодом из настроек ПК.
- Настройки внешнего вида у каждого устройства свои.

Настройка: ⚙ → «Синхронизация между устройствами» → «Как настроить».

## Корпоративный Google Календарь (ПОРТАЛ)

Если администратор Google Workspace запретил публичный и секретный адрес календаря
(встречи приходят как «Busy»), календарь отдаёт ваш собственный скрипт
`google-apps-script/calendar-feed.gs` — со всеми названиями, временем, местом и описанием.

**Если скрипт уже создан** и нужна только ссылка: script.google.com → проект →
«Начать развёртывание» → «Управление развёртываниями» → скопировать URL веб-приложения (`…/exec`).

**Создать с нуля:**
1. script.google.com под рабочей почтой → «Новый проект».
2. Вставить код из `google-apps-script/calendar-feed.gs`
   (в программе: ⚙ → «Календарь» → «Добавить календарь» → «Корпоративный Google» → «Скопировать код скрипта») → Ctrl+S.
3. ⚙ «Настройки проекта» → часовой пояс (GMT+03:00) Москва.
4. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»;
   «Запуск от имени»: Я; «У кого есть доступ»: Все → «Начать развёртывание».
5. Разрешить доступ к календарю («Дополнительно» → «Перейти к проекту» → «Разрешить»).
6. В программе: ⚙ → «Календарь» → «Добавить календарь» → название «Расписание (ПОРТАЛ)»,
   ссылка — URL `…/exec` → «Добавить по ссылке».

После любой правки кода: «Управление развёртываниями» → ✏ → «Новая версия» → «Развернуть»
(иначе работает старая версия и программа покажет «forbidden»). Ссылка при этом не меняется.

Встречи загружает программа на ПК, на телефон они приходят синхронизацией.

## Где хранятся данные локально

В программе — локальное хранилище Electron (папка данных пользователя Windows), на телефоне — хранилище Safari.
Ручная копия — ⚙ → «Данные» → «Экспорт (JSON)» (токены в файл не попадают).
