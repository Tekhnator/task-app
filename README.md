# Задачи

Настольная программа-планировщик для Windows (Electron): папки и списки, задачи с
форматированием и картинками, дедлайны, календарь с праздниками, встречами и своими
календарями (iCal), виджеты в шапке (часы с календарём, калькулятор, секундомер,
погода с прогнозом на 7 дней, поиск), голосовой ввод через диктовку Windows,
темы оформления TRON, iPhone и Unibody (светлые и тёмные).

## Запуск

1. Установите [Node.js](https://nodejs.org) (LTS).
2. В папке программы один раз выполните `npm install`.
3. Запуск — `Запуск.bat` (или `npm start`).
4. Установщик для Windows — `npm run build`, результат в папке `dist`.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение: интерфейс и логика. Можно открыть и просто в браузере. |
| `main.js` | Окно программы; сетевые запросы (погода, праздники, календари), вход в Google, вызов диктовки Windows. |
| `preload.js` | Мост между страницей и программой (`nativeNet`, `nativeGoogle`, `nativeVoice`). |
| `google-apps-script/calendar-feed.gs` | Скрипт, отдающий корпоративный Google Календарь ссылкой iCal (инструкция внутри файла). |

## Где хранятся данные

В программе (локальное хранилище Electron, папка данных пользователя Windows).
Резервная копия — ⚙ → «Данные» → «Экспорт (JSON)»; перенос на другое устройство — «Импорт (JSON)».
