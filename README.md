# task-app

Планировщик задач: папки, списки, задачи с форматированием и картинками, дедлайны,
виджеты (часы, секундомер, калькулятор), свои темы оформления.

## Где открыть

Приватная страница Claude (видна только владельцу):
https://claude.ai/artifact/LjetEcyF3XcmSNMjTMnoQ6

Одна и та же ссылка на компьютере и на телефоне. Задачи, списки и папки
синхронизируются между устройствами через облако. Настройки внешнего вида
(тема, размер шрифта, виджеты) у каждого устройства свои.

## Как устроена синхронизация

- Задачи хранятся в 128 документах-«корзинах» (`pbuckets/b0…b127`) по хешу id задачи;
  правка одной задачи отправляет в облако только её.
- Папки и списки лежат в документе `planner/meta`.
- Порядок задач хранится весом `ord` (больше = выше), поэтому перестановка одной задачи
  не переписывает весь список.
- Копия данных хранится и в браузере, так что приложение открывается сразу,
  а облачная версия подтягивается следом.

## Что не работает в версии по ссылке

Страница Claude не пускает запросы к сторонним сайтам и микрофон, поэтому не работают:
погода, праздники из интернета, Google Календарь, голосовой ввод.
Экспорт дедлайнов сохраняется как `.ics.txt` (перед импортом в календарь переименуйте в `.ics`).
