# task-app

Приложение для задач.

## Что умеет

- добавлять задачи со сроком: без срока, сегодня, завтра или на выбранную дату;
- отмечать задачи выполненными и возвращать их в работу;
- показывать активные, выполненные и все задачи;
- подсвечивать просроченные задачи;
- удалять задачи с возможностью отменить удаление.

## Где открыть

Приложение опубликовано как приватная страница Claude (доступна только владельцу):
https://claude.ai/artifact/LjetEcyF3XcmSNMjTMnoQ6

Там задачи синхронизируются между телефоном и компьютером.

## Файлы

- `index.html` — всё приложение в одном файле (разметка, стили, скрипт).
  Если открыть его вне Claude, задачи сохраняются только в браузере этого устройства.
